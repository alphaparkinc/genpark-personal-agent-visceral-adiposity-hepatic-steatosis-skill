## MCP Tools Exposed
- `compute_visceral_adiposity_index`: Compute clinical Visceral Adiposity Index (VAI) from waist circumference, BMI, triglycerides, and HDL.
- `synthesize_visceral_fat_reduction_plan`: Synthesize targeted nutrition and exercise plan to mobilize ectopic visceral and hepatic adipose stores.
